# Developer's Way — External Lab

Evidence decides; owner accepts the technical claim. Distinguish IMPLEMENTED, TESTED, VERIFIED, QUALIFIED, BLOCKED, and UNKNOWN. Loading is not qualification; model prose is not verification.

Inspect → lock exact mission and identities → execute only authorized steps → preserve failures → independently verify → hash evidence → submit PR. Q0 is offline/read-only except evidence writes. Later egress/model downloads require an activated mission with pinned source/artifact and owner approval. Never turn unavailable into pass.
