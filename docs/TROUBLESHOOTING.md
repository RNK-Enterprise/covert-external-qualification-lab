# Troubleshooting

- Node/OS mismatch: retain observation and mark REVIEW_REQUIRED.
- Missing runtime/cache: record NOT_INSTALLED/ABSENT; do not install.
- Ambiguous root/resource pressure: stop and preserve partial evidence.
- Hash pending: artifact identity is not established.
- Q1 runner refusal: gated; do not create activation state or bypass.
- Verifier red: preserve first failure; corrections require a new run ID.
