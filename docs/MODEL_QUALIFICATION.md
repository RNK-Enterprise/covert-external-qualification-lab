# Model Qualification

Bind exact model ID, source/revision, artifact hashes, architecture, quantization, tokenizer/chat template, context, runtime/backend/profile, hardware, battery/scorer revision, license, and limitations. Friendly names are hints. Unknown identity is not qualification.

Q1 is one small exact-model pipeline proof after disclosure-safe Covert and product gates pass. Q2 follows Q1 review. Qualification is role/environment specific; no universal best-model score.
