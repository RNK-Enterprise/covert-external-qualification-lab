# Experiment Design

Q1 proves the pipeline with one small pinned model, not capability. Lock fixture, effects, verifier, budget, resources, egress and cleanup first.

Q2 selects exact models from inventory/admission. Do not tune prompts or scoring after outcomes.

Q3 pairs raw/reference and Covert Harness on the same machine, artifact, task, context, tool affordance, approval, budget and timeout; alternate order. If affordances differ, mark NON_EQUIVALENT. Measure task success, independent verification, regressions, constraints, unsupported claims, tool errors, recovery, retries, operator interventions, time, tokens, RAM/VRAM/CPU, TTFT/tok/s, evidence quality. One run is smoke evidence, not comparison.

Q4 replays locked experiments across owner laptop, Phoenix and Atlas; retain backend differences.
