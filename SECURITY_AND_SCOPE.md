# Security and Scope

Barry is an external qualification operator/runtime evidence node. He supplies evidence; canonical Covert systems decide qualification and promotion. No Covert Engine, Authority, signing, production CI, credentials, or canonical Model Intelligence authority is delegated.

Never include Covert Engine source, Authority/private Model Intelligence internals, credentials/tokens/keys, device identity material, production secrets, owner-private tasks, internal configuration, or readable implementation trees from a Covert package. The ordinary desktop package is not approved for external use.

Q0 is static inventory: no downloads, inference, installs, network tests, privileged commands, time-series telemetry, or shared OpenCode session inspection. Authority, approvals, resource admission, credentials, egress, and qualification stay distinct.

Review evidence and archives before PR. If secret/private data is suspected, stop and quarantine locally; do not paste it into an issue/chat.
